# Drift Car Desktop Pet

A transparent macOS desktop companion that follows the cursor with a 3D Nissan S14 model, controlled drift motion, tire smoke, and short skid streaks.

## Run

1. Install Node.js and npm.
2. Run `npm install` in this folder.
3. Run `npm start`.

Quit with `Command + Shift + Q` (or `Control + Shift + Q`).

## Customize

Edit `renderer.js` to adjust movement, drift, smoke, lighting, and model scale. The model and textures are in `assets/s14/`.
